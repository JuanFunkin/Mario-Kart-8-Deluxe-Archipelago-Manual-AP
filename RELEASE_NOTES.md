# v1.0.0 - First release

First public release of the **Mario Kart 8 Deluxe** Manual APWorld for Archipelago (base game, no DLC).

## What's included
- 200 checks generated automatically in the Manual Client:
  - 32 track checks (finish a race on each base-game track)
  - 160 speed checks (every track on 50cc, 100cc, 150cc, Mirror Mode and 200cc)
  - 8 cup checks (1st place in each cup's Grand Prix, any speed)
- 3 goals: all tracks, 1st place in all cups, or everything complete.
- YAML options to turn each check type and each speed on or off.
- You receive nothing: this world only sends items to other players (the only item is a `Nothing` filler).

## Install
1. Put `manual_mariokart8deluxe.apworld` in your Archipelago `custom_worlds` folder.
2. Edit `Manual_MarioKart8Deluxe.yaml` (set your `name`) and put it in `Players`.
3. Connect with Manual Client from the Archipelago Launcher.

## Requirements
Archipelago 0.5.0 or newer (only tested so far on a 0.6.x build).
